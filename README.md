# SAE Aqiqah — Digital Marketing Book (HTML)

Kumpulan aset HTML untuk digital marketing SAE Aqiqah.

## Struktur File

- `index.html` — Halaman utama (navigasi ke semua section)
- `brand-guideline.html` — Panduan brand identity (warna, tipografi, logo usage)
- `website.html` — Demo website SAE Aqiqah yang sudah dioptimasi
- `content-carousel-posts.html` — 20 template carousel post siap pakai (Instagram & TikTok)
- `content-plan.html` — Content plan 20 ide carousel dengan playbook

## Cara Menggunakan

1. Buka `index.html` di browser
2. Klik card untuk membuka halaman terkait
3. Setiap halaman memiliki link "← Home" / "← Kembali ke Index" untuk kembali

## Best Practice yang Diterapkan

- Semua nama file menggunakan lowercase + hyphen (best practice untuk GitHub & web)
- Internal link sudah diupdate ke nama file baru
- Navigasi antar halaman ditambahkan di setiap section

## Upload ke GitHub

Cukup push folder ini. Semua link relatif akan berfungsi normal di GitHub Pages atau Netlify.
